# Repository instructions

Before working here, read `context.md`, `COURSE_PLAN.md`, and
`course-notes/PROGRESS.md` if present.

`article-wave` is the active project. Make changes here; treat
`../llm-twin-course` and `../medium articles` as read-only references.

Default status/progress questions refer to `article-wave`, not the reference
course repo.

Application data is limited to public Medium articles, public Substack posts,
and user-created notes. Do not add GitHub, LinkedIn, email, calendar, chat,
social, private, or paywall-bypassed content as data unless the user explicitly
changes scope. GitHub may still host this source code.
